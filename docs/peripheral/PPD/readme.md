# PostScript Printer Description

[![License](https://img.shields.io/badge/license-MIT-blue.svg)](/LICENSE)
[![Stars](https://img.shields.io/github/stars/teanrus/redos-lifehacks.svg)](https://github.com/teanrus/redos-lifehacks/stargazers)

Библиотека PPD-файлов (PostScript Printer Description) для различных моделей принтеров. Эти файлы используются CUPS для настройки и управления функциональностью принтеров.

## Источники PPD-файлов

Часть файлов PPD заимствованы из следующих проектов:
- **[foo2zjs](https://github.com/koenkooi/foo2zjs/tree/master)** — драйверы для принтеров ZJS (Zenographics)
- **[Print-PPD](https://github.com/liberodark/Print-PPD)** — коллекция PPD-файлов для различных принтеров

## Развитие библиотеки

Библиотека PPD-файлов регулярно пополняется новыми файлами для поддержки дополнительных моделей принтеров. Приветствуются вклады в виде новых PPD-файлов через pull requests.
