## Назначение

Скрипт `package-install-fix.sh` — это **интерактивный мастер диагностики и исправления** типичных проблем при установке пакетов в РЕД ОС. Он автоматически выявляет и предлагает устранить:

- Проблемные репозитории
- Нехватку места на диске
- Конфликты и неразрешённые зависимости
- Незавершённые транзакции DNF
- Повреждённые пакеты
- Проблемы с GPG-ключами
- Lock-файлы и повреждённую базу RPM

Скрипт **требует прав root** и работает в интерактивном режиме, запрашивая подтверждение перед каждым действием.

## Использование

```bash
# Вариант 1: Быстрый запуск (curl)
curl -sL https://github.com/teanrus/redos-lifehacks/releases/latest/download/package-install-fix.sh | sudo bash

# Вариант 2: Быстрый запуск (wget)
wget -qO- https://github.com/teanrus/redos-lifehacks/releases/latest/download/package-install-fix.sh | sudo bash

# Вариант 3: Скачивание с проверкой целостности
curl -sL https://github.com/teanrus/redos-lifehacks/releases/latest/download/package-install-fix.sh -o package-install-fix.sh
curl -sL https://github.com/teanrus/redos-lifehacks/releases/latest/download/package-install-fix.sh.sha256 -o package-install-fix.sh.sha256
sha256sum -c package-install-fix.sh.sha256
sudo bash package-install-fix.sh
```

> [!important]
> Скрипт требует прав `root` (sudo). Запуск от обычного пользователя будет прерван.

### Опции

| Опция | Описание |
|-------|----------|
| `-h`, `--help` | Показать справку |
| `-p`, `--package <имя>` | Исправить конкретный пакет |

## Что проверяет скрипт

| Этап | Описание | Действия |
|------|----------|----------|
| **1. Информация о системе** | Версия ОС, ядро, архитектура, место на диске | Вывод предупреждений при >80% заполненности |
| **2. Репозитории** | Список и доступность репозиториев | Отключение нерабочих репозиториев |
| **3. Место на диске** | Проверка `/var` и системных разделов | Очистка кэша DNF, старых ядер, логов |
| **4. Зависимости** | Конфликты и неразрешённые зависимости | `dnf distro-sync` для исправления |
| **5. Очистка кэша и RPM** | Кэш DNF, lock-файлы, база RPM | `dnf clean all`, `rpm --rebuilddb` |
| **6. Транзакции DNF** | История и незавершённые транзакции | Откат незавершённых транзакций |
| **7. Целостность пакетов** | `rpm --verify` — проверка битых файлов | Переустановка повреждённых пакетов |
| **8. GPG-ключи** | Список и импорт ключей РЕД ОС | Импорт `/etc/pki/rpm-gpg/RPM-GPG-KEY-redos` |
| **9. Тестовая установка** | Установка `htop` для проверки | Проверка успешности установки |

## Решение типичных проблем

### Ошибка: `Cannot download repomd.xml`

**Причина:** Репозиторий недоступен или неверный URL.

**Решение:** Скрипт обнаружит проблемный репозиторий и предложит его отключить:

```bash
dnf config-manager --set-disabled проблемный-репо
```

---

### Ошибка: `Problem: package X conflicts with package Y`

**Причина:** Два пакета несовместимы.

**Решение:**

```bash
# Проверка конфликтов
rpm --verify -a 2>/dev/null | grep conflict

# Исправление через скрипт
sudo ./package-install-fix.sh
# → Согласиться на исправление зависимостей
```

---

### Ошибка: `Lock error: /var/lib/dnf/lock`

**Причина:** Другой процесс DNF не завершён или lock-файл остался.

**Решение:**

```bash
# Удаление lock-файлов
sudo rm -f /var/lib/dnf/lock /var/lib/rpm/__db*
sudo rpm --rebuilddb
```

---

### Ошибка: `Public key for package.rpm is not installed`

**Причина:** GPG-ключ репозитория не импортирован.

**Решение:**

```bash
sudo rpm --import /etc/pki/rpm-gpg/RPM-GPG-KEY-redos
sudo rpm --import /etc/pki/rpm-gpg/RPM-GPG-KEY-redos-release
```

---

### Ошибка: `Transaction in progress`

**Причина:** Незавершённая транзакция DNF.

**Решение:**

```bash
# Просмотр незавершённых транзакций
dnf history list incomplete

# Откат
dnf history undo <ID> -y
```
