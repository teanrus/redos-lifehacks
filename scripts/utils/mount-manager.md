## Общее описание

Скрипт предназначен для управления монтированием сетевых директорий (CIFS/SMB) в операционной системе РЕД ОС. Предоставляет как интерактивный режим работы с меню, так и режим командной строки с аргументами.

## Использование

**Запуск:**

```bash
# Вариант 1: Быстрый запуск (curl)
curl -sL https://github.com/teanrus/redos-lifehacks/releases/latest/download/mount-manager.sh | sudo bash

# Вариант 2: Быстрый запуск (wget)
wget -qO- https://github.com/teanrus/redos-lifehacks/releases/latest/download/mount-manager.sh | sudo bash

# Вариант 3: Скачивание с проверкой целостности
curl -sL https://github.com/teanrus/redos-lifehacks/releases/latest/download/mount-manager.sh -o mount-manager.sh
curl -sL https://github.com/teanrus/redos-lifehacks/releases/latest/download/mount-manager.sh.sha256 -o mount-manager.sh.sha256
sha256sum -c mount-manager.sh.sha256
sudo bash mount-manager.sh
```

**Команды:**

```bash
# Запуск интерактивного меню
sudo ./mount-manager.sh

# Список смонтированных шар
sudo ./mount-manager.sh --list

# Добавить новую шару
sudo ./mount-manager.sh --add

# Размонтировать шару
sudo ./mount-manager.sh --remove

# Загрузить пресет из конфига
sudo ./mount-manager.sh --load

# Монтировать все шары из fstab
sudo ./mount-manager.sh --mount-all

# Показать справку
sudo ./mount-manager.sh --help
```

## Конфигурация и файлы

| Файл | Описание |
|------|----------|
| `/etc/mount-manager.conf` | Пресеты подключений (INI-формат) |
| `/etc/fstab` | Таблица файловых систем (автомонтирование) |
| `/root/.smbuser_<login>` | Файлы учётных данных (права 600) |

### Формат пресета

```ini
[myshare]
server=192.168.1.100
share=public
username=user
password=pass
domain=
is_domain=0
```

### Параметры монтирования

| Опция | Описание |
|-------|----------|
| `credentials=<file>` | Файл учётных данных |
| `nobrl` | Отключение byte-range locks |
| `iocharset=utf8` | Кодировка имён файлов |
| `file_mode=0777` | Права на файлы |
| `dir_mode=0777` | Права на директории |
| `nofail` | Не блокировать загрузку (для доменных шар) |

---

## Основные функции

### Монтирование шары

```bash
mount -t cifs "//<server>/<share>" /mnt/<name> -o credentials=<file>,nobrl,iocharset=utf8,file_mode=0777,dir_mode=0777[,nofail]
```

### Размонтирование

При ошибке обычного размонтирования скрипт пытается принудительное (`umount -l`), затем удаляет директорию.

### Загрузка пресета

1. Вывод списка доступных пресетов из `/etc/mount-manager.conf`
2. Выбор по номеру
3. Создание файла учётных данных
4. Монтирование с подтверждением

## 📋 Требования и совместимость

| Параметр | Значение |
|----------|----------|
| **ОС** | РЕД ОС 7.3 / 8.0 |
| **Архитектура** | x86_64 / aarch64 |
| **Ядро** | 3.7+ (опция `nobrl`), 3.9+ / util-linux 2.27+ (опция `nofail`) |
| **Система инициализации** | systemd (автомонтирование через fstab) |
| **Права** | root (монтирование, запись в fstab, файлы учётных данных) |
| **Зависимости** | bash 4.0+, cifs-utils (mount.cifs), coreutils, grep, sed |
| **Опционально** | smbclient (диагностика SMB) |
| **Скрипт** | mount-manager.sh (bash 4.0+) |
| **Конфиг** | `/etc/mount-manager.conf` (пресеты подключений, INI-формат) |
| **Учётные данные** | `/root/.smbuser_<login>` (права 600) |
| **Совместимость** | ✅ РЕД ОС 7.x, ✅ РЕД ОС 8.x (может работать на других RPM-дистрибутивах: Fedora, RHEL, CentOS, Astra Linux, Alt Linux) |

> [!note]
> В РЕД ОС 7.x версии `mount.cifs` и `util-linux` могут быть старее — опции `nobrl` и `nofail` могут отсутствовать. Перед использованием рекомендуется проверить `mount.cifs --help`.
> В дистрибутивах с SELinux (RHEL, CentOS, Fedora) может потребоваться `restorecon -v /root/.smbuser_*` для корректного доступа к файлам учётных данных.

## Безопасность

- Файлы учётных данных создаются с правами `600`
- Конфигурационный файл защищён правами `600`
- Пароли хранятся в файлах в открытом виде (требуется защита директории `/root`)

## Особенности

- Поддержка как локальных, так и доменных шар
- Автоматическое создание точек монтирования
- Интеграция с `/etc/fstab` для автоматического монтирования
- Система пресетов для быстрого повторного подключения
- Подробная диагностика ошибок при проблемах с монтированием
